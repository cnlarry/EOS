EOS 是权限边界与审计驱动的 ERP 系统，安全约束是硬性验收项。权威规则以 `AGENTS.md`「不可逾越的架构约束」和 `EOS.API/README.md` 为准，本文是逐项自检清单。

## 1. API 是最终权限边界

- [ ] 前端权限判断只改善体验，服务端必须重新授权（同模块前后端都要校验）。
- [ ] Agent 不得绕过 API 直接访问数据库。
- [ ] 新增端点检查：未登录 401、无模块权限 403（`EXEC_TAG`/个人覆盖组/SYSDD 优先语义）。
- [ ] 写端点校验对应动作权限位（批核/结案/附件等），不止 `CanBrowse`。

## 2. 动态 SQL / 元数据

- [ ] 动态表名、字段名、排序、查询字段来自服务端白名单/Definition，不信任前端提交。
- [ ] 动态查询结构化条件 + 参数化 SQL，无字符串拼接用户值。
- [ ] 子表查询依赖有效主表关联键，缺关联条件禁止读取。
- [ ] `VIRTUAL_EXP`/`CONVERT_FUNCTION`/`DATASOURCE_SQL`/`DATA_FILTER` 未受控解析不进入 SQL/运行时。
- [ ] 元数据查询用 `sys.*`，不用 `INFORMATION_SCHEMA`。

## 3. 数据范围（WorkbenchScopeFilter）

- [ ] 列表/详情/子表/导出/打印/建单/改单/删单/选择器数据范围口径一致（模块 FILTER + DATA_FILTER + EXEC_TAG，fail-closed）。
- [ ] 成本/保密/禁止字段在查询、导出、打印、选择器全链路被过滤，不能构造请求读取。
- [ ] 内部行键（`__rowKey`）与显示列元数据分离，不把隐藏关键字段重新作为显示列返回。

## 4. 写路径与审计

- [ ] 写操作走服务端校验、状态机、事务、幂等键与审计（AUDIT_EVENT）。
- [ ] 删除补偿守卫：结案单据禁删、已批核且有副作用 SP 禁删、已产生库存日志禁删。
- [ ] 批核/解批/结案/未结案状态迁移由服务端权威判定。
- [ ] 金额/数量/日期精度以服务端为准；ID 前端按字符串处理。

## 5. 敏感信息

- [ ] 不提交数据库密码、旧密码密文、Cookie 密钥或任何敏感凭据到代码库。
- [ ] 日志不包含密码、Token、查询参数值或敏感业务值。
- [ ] 登录失败限流/锁定、CSRF 同源校验不被改动弱化。

## 完成标准

- 越权场景（无权限用户构造请求读取/导出/打印）在 E2E 或手动验证中返回 401/403/404；
- 以上清单全绿后调用 `eos-verify` 跑验证与回归。
