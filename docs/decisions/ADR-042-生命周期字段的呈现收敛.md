# ADR-042：生命周期字段的呈现收敛

> 列名已由 [ADR-043](ADR-043-生命周期列命名收敛.md) 收敛（2026-10-25）；本篇的呈现语义不变，
> 正文旧列名保留为历史，不再作为当前字段名的依据。

- 状态：已接受（2026-10-25 用户拍板）
- 日期：2026-10-25
- 决策者：用户（Larry）+ 开发 Agent
- 相关：ADR-006（统一表单）、ADR-010（可视化版式设计器）、ADR-013（单据生命周期列规约）、ADR-022（统一表单版式）、ADR-035（批核模型收敛）

## 1. 背景

建立/修改/批核/结案的人·日期·状态位（`WorkflowStates.LifecycleColumns`，共 10 列）此前被当作
**可参与版式的表单字段**：

- 服务端在 `new` / `edit` 态把这 10 列剔除，只有 `view` 态下发并标只读；
- 前端新增/编辑只对下发字段装箱，设计器却对全部版式行装箱；
- 设计器还把它们标成"单据系统列，始终显示"——可以拖动、不能删除。

于是同一张表单出现三副样子：设计态有、新增/编辑没有、浏览态按版式出现。库内实测（2026-10-25）：

- 263 个有版式的模块里，258 个带生命周期行，共 2046 行；
- 179 个模块把生命周期列**穿插**在业务字段之间，只有 79 个收在末尾；
- 73 个页签去掉这些行后会变成空页签；
- 浏览态的状态位被渲染成禁用复选框，10 个字段散落在不同页签里。

根因不是样式，而是**把记录元信息混进了录入版式模型**。

## 2. 决策

### 2.1 生命周期字段不参与版式

- 服务端在 `FormDefinition` 中把 10 列分流到 `LifecycleFields`（仅 `view` 有值），
  `MasterFields` 只保留业务字段；
- `FormLayoutDerivation`、`FormLayoutRepository`、`FormLayoutSubmission` 三处都过滤生命周期行：
  存量版式行读取时忽略、下一次保存时丢弃，不要求数据迁移；
- 设计器字段池与画布不再出现这些字段，只消费 `FormLayoutDesignState.SystemFields` 在画布下方画固定区预览。

### 2.2 浏览态按语义收成两处

| 信息 | 位置 | 说明 |
|---|---|---|
| 批核/结案状态 | 工具栏右侧徽标 | `未批核` / `审批中` / `已批核`、`未结案` / `已结案`；始终可见 |
| 建立/修改/批核/结案的人与日期 | 主表单卡底部固定区 | 不占页签、不随字段区滚动；组宽等分 |

- **无结案能力的模块**（主表没有 `FINISHED_TAG` 物理列）只显示批核状态，底部只有
  建立/修改/批核三组等分；
- 结案能力是**模块能力**（`FormDefinition.HasFinishCapability`，与 `RunFinishCoreAsync` 同源），
  不是当前用户的 `ENDCASE_TAG` 权限位；
- 固定区没有可见标题（用户明确要求移除"单据信息"四字），语义由 `aria-label` 承担；
- 记录未到达时不渲染状态/固定区，避免先显示"未批核"再翻成"已批核"。

### 2.3 空页签不渲染

某个页签在当前用户可见业务字段里一个都没有时，运行态不显示该标签；设计器保留页签并标"空"，
提示"空页签运行态不显示"。这同时修掉了 73 个模块的空 tab 2。

## 3. 后果

- 契约新增 `FormDefinition.LifecycleFields` / `HasFinishCapability`；
  `GetRecordAsync` 把生命周期字段并入 SELECT（记录读取契约仍返回它们）。
- 前端新增 `LifecycleStatusBar` / `LifecycleInfoBlock`，与设计器共用 `buildLifecycleGroups` 纯函数。
- 状态位不再是禁用复选框；业务字段在新增/编辑/浏览三种状态下的格位一致。
- 不做库迁移、不批量重发布：读取侧过滤即生效；只有主动清理历史版式行时才需要重发布。
- 文档同步：[42-统一表单](../guide/42-统一表单.md)、[43-表单版式设计](../guide/43-表单版式设计.md)、
  [48-生命周期与审批流](../guide/48-生命周期与审批流.md)。

## 4. 被否决的方案

| 方案 | 否决理由 |
|---|---|
| 保留版式，强制收进一个"系统信息"页签/分节 | 状态被藏进页签；73 个模块仍会出现空页签；设计态仍可移动，三副样子没有消除 |
| 只把状态位改成徽标，字段仍散在版式里 | 解决"复选框难看"，不解决设计态/运行态不一致 |
| 给每个模块加"是否显示审计区"开关 | 增加一处逐模块配置；用字段存在性与权限自然显隐即可，不需要 |
| 把 10 个字段全部放到工具栏 | 工具栏承载动作，塞 8 个只读时间会挤掉动作；追溯信息也不该常驻在动作区 |
