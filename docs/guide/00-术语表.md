# 00 术语表

本手册与代码里反复出现的名词，先在这里统一口径。每条的「详见」指向讲透它的篇目。

## 一、系统与工程

| 术语 | 含义 |
|---|---|
| EOS | 本系统。由两个工程构成：`EOS.API`（后端）、`EOS.Web`（前端） |
| `EOS.ERP` | **唯一的业务库**（SQL Server）。所有库对象都建在这里，不为功能单独建库 |
| 元数据驱动 | 界面形态由库内元数据决定，而不是由前端页面代码写死。改元数据即改界面 |
| 迁移 | `EOS.API/Data/Migrations/` 下的 `NNN_描述.sql`，服务启动时由 DbUp 按文件名顺序自动执行 |
| 迁移台账 | `dbo.ERP_SCHEMA_JOURNAL`。DbUp 按**资源名（即脚本文件名）**判重，只执行没记录过的脚本 |
| 定义（Definition） | 服务端为某个模块解析出的完整运行配置：表、字段、列、布局、动作、规则等。工作台与表单都按定义运行 |
| 定义快照 | 定义序列化后落库的产物，供运行时直接读取，避免每次请求重新推导 |
| 脏标记 | 标记"定义已过期、需要重新发布"的开关。配置改了但快照没重发布，就是静默落后 |

## 二、元数据

| 术语 | 含义 |
|---|---|
| 模块（`MODULES`） | 业务单元。单据、报表、权限都以模块为锚点。`M_IDX` 是模块编号 |
| 模块树 | 模块之间的层级关系，决定菜单导航结构 |
| 表（`TABLES`） | 登记哪些物理表/视图可供界面使用 |
| 字段（`FIELDS`） | 登记哪些物理列可供界面使用，以及它的显示名、控件类型、是否必填、是否只读等 |
| 字段显示名（`F_DESC`） | 字段在界面上显示的标签（不是数据库列名） |
| 自定义列配置（`SYSQL_FIELDS`） | 用户自己选的列表列与顺序 |
| 系统默认列（`SYSQL_DEFAULT`） | 用户没有自定义时使用的默认列 |
| 虚拟字段 | `FIELDS.IS_VIRTUAL=1` 的字段。它的值由表达式算出，库里没有对应的物理列 |
| 模块级版式 | 模块自定义的表单排布（哪些字段同排、跨几列），存在 `MODULE_FORM_LAYOUT` |

详见 [10-元数据模型](./10-元数据模型.md)、[11-元数据运维](./11-元数据运维.md)、[12-元数据消费](./12-元数据消费.md)。

## 三、单据

| 术语 | 含义 |
|---|---|
| 单据 | 一条业务记录：一张单头 + 若干行明细 |
| 主表 | 单据表头对应的物理表 |
| 子表 / 明细表 | 单据行项目对应的物理表，靠关联键挂回主表 |
| 主子表 | 主表 + 子表的组合形态，是绝大多数单据的形态 |
| 统一工作台 | `DocumentWorkbench`。单据的**列表态**页面：检索、排序、分页、选择列、进入单据 |
| 统一表单 | 单据的**浏览态/编辑态**页面：字段渲染、主子联动、单据级动作 |
| 工作区 | 顶部多标签区域，可同时打开多个单据或页面 |

详见 [40-统一工作台](./40-统一工作台.md)、[42-统一表单](./42-统一表单.md)。

## 四、生命周期与状态

| 术语 | 含义 |
|---|---|
| 生命周期列 | 单据主表上承载状态的**一组标准列**：状态位、经办人、日期等。列名与约束有统一口径 |
| 批核 / 解批 | 把单据置为已确认 / 撤销确认。对应主表上的确认状态位 |
| 结案 / 取消结案 | 把单据置为已结束 / 撤销结束，结案后一般禁止再改 |
| 状态位 | 承载上述状态的布尔列（如确认标志、结案标志），约束为 `NOT NULL DEFAULT` |
| 审批历史 | 单据历次批核/结案等状态变迁的记录 |
| 工作流引擎 | 按配置驱动单据在状态之间流转的运行时 |
| 效果（Effect） | 单据动作的**配置化实现**：一次动作由一串有序效果步骤组成（写库、校验、联动等） |
| 业务动作 | 用户可触发的动作（批核、结案、自定义按钮…），与效果配置绑定 |

详见 [47-单据行为效果引擎](./47-单据行为效果引擎.md)、[48-生命周期与审批流](./48-生命周期与审批流.md)。

## 五、权限

| 术语 | 含义 |
|---|---|
| 权限键 | `资源.动作` 形式的字符串，例如 `purchase-order.read`、`legacy-module.2303.read` |
| 模块操作位 | 模块级的功能开关（能否浏览/新增/修改/删除/批核…） |
| 字段级权限 | 细到字段的三类禁止：**禁看**（不返回）、**禁改**（可读不可写）、**禁新增**（可改不可插） |
| 数据范围（DA） | 行级过滤：只让用户看到其权限范围内的数据 |
| 个人权限（`SYSDD`） | 直接授给某个用户的模块权限 |
| 组权限（`SYSDH`） | 授给用户组、再由用户继承的模块权限 |
| 覆盖规则 | **个人权限覆盖组权限**：只要有个人权限记录，就完全采用个人权限，不再合并组权限 |
| 聚合规则 | 多组之间：布尔位取 OR；`EXEC_TAG` 从 `A` 起按字符串取最大；禁止字段取各组的**交集** |
| `REPORT_TAG` | 报表可见性的唯一真源（取归属模块的报表权限位） |

详见 [20-认证与会话](./20-认证与会话.md)、[21-授权模型](./21-授权模型.md)、[22-权限配置后台](./22-权限配置后台.md)。

## 六、查询与表达式

| 术语 | 含义 |
|---|---|
| 结构化条件 | 前端提交的查询条件**不是 SQL**，而是"字段 + 运算符 + 值"的结构，由服务端编译成参数化 SQL |
| 条件模板 | 预置的查询条件集合，按模块存放（`SYSQR_DEFAULT` 默认、`SYSQR_USER` 用户自定） |
| 受控表达式 | 存库的表达式（虚拟列、转换、过滤），进入 SQL 前必须先经过服务端解析与白名单校验 |
| `VIRTUAL_EXP` | 虚拟列的表达式。只在 `IS_VIRTUAL=1` 的字段上生效 |
| `CONVERT_FUNCTION` | 字段的转换表达式 |
| `DATA_FILTER` | 字段的数据过滤表达式 |
| 统一选择器 | `UnifiedChooser`。凡"从既有业务数据中挑记录"的输入，都用它 |
| 数据源 | 选择器的数据来源，只允许两种：`formField`（复用表单字段元数据）与 `sourceKey`（服务端注册的数据源） |

详见 [44-受控查询与条件模板](./44-受控查询与条件模板.md)、[45-受限表达式与虚拟字段](./45-受限表达式与虚拟字段.md)、[46-统一选择器](./46-统一选择器.md)。

## 七、报表

| 术语 | 含义 |
|---|---|
| 报表 | 一份可查询、可导出、可打印的取数定义。身份是 `reportId` |
| 报表资源 | 报表作为一种可被引用的资源（有归属、有权限、有入口） |
| 归属模块 | `REPORT.M_IDX`。报表挂在某个业务模块下，权限与条件都跟着该模块走 |
| 报表中心 | 报表的统一目录与检索入口。报表不进菜单 |
| 报表收件箱 | 定时生成/订阅的报表结果投递处 |
| 聚合注册表 | `ReportAggregateRegistry`。跨表聚合的唯一出口 |
| 版式（layout） | 报表/单据的打印排布定义，`kind` 区分单据版式与列表版式 |
| 版式资产 | 落盘的版式定义文件（`layout.json`），由解释层渲染，不写命令式渲染代码 |

详见 [50-统一报表](./50-统一报表.md)、[51-报表可视化设计器](./51-报表可视化设计器.md)、[52-报表打印版式](./52-报表打印版式.md)。

## 八、平台能力

| 术语 | 含义 |
|---|---|
| 附件 | 挂在单据字段上的文件。**元数据在库、文件在磁盘**，访问按字段位强制鉴权 |
| 作业（Job） | 可被调度执行的服务端任务，支持定时触发与手动触发 |
| 搜索中心 | 全局检索入口，检索面受当前用户权限过滤 |
| 系统参数 | 可配置的运行时参数，有类型、分组、默认值与生效范围 |
| 期间关账 | 把某个会计期间置为关闭，之后禁止再往该期间记账 |
| 库存维度 | 库存的细分口径：库别、库位、批次等 |
| 预留 / 冻结 | 对库存的两种占用：预留（计划占用）与冻结（临时锁定） |
| 可用量 | `USEABLE_QTY = QTY − Σ(有效冻结) − Σ(有效预留)` |

详见 [70-后台配置面总览](./70-后台配置面总览.md)、[71-附件](./71-附件.md)、[73-作业与调度](./73-作业与调度.md)、[74-搜索中心](./74-搜索中心.md)。

## 九、AI 工作助手

| 术语 | 含义 |
|---|---|
| 工作助手 | 内嵌在 `EOS.Web` 中的 AI 助手，模型推理内聚在 `EOS.API/Features/Assistant` |
| 语义接口 | 助手读取业务数据的受控入口：只暴露受权限约束的语义化查询，不让模型接触 SQL |
| 操作代理 | 助手代用户执行业务动作的机制，动作执行仍走 API 的正常鉴权与校验 |
| 知识库 | 供助手检索的项目/业务知识，可被摄入与索引 |
| 记忆 | 助手跨会话保留的用户偏好与上下文 |

详见 [60-AI工作助手](./60-AI工作助手.md)。

## 十、开发过程用语

| 术语 | 含义 |
|---|---|
| 门禁脚本 | `scripts/` 下以 `check-` 开头的自检脚本，用于拦住"编译与单测发现不了、只在运行时炸"的缺陷 |
| 棘轮 | 门禁对存量问题的处理方式：允许既有命中，但**只减不增**，新代码不得加重 |
| 自检（`-SelfTest`） | 门禁脚本对自身判别力的验证：构造正例与反例，确认能正确区分 |
| 对拍 | 用同一输入跑两套实现，比对结果是否语义等价 |
| 干跑 | 迁移脚本的试运行：执行后回滚，确认语法与事务配平，但不真正落库 |
